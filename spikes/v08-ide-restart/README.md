# V8：IDE への R の再起動の指示と、起動時の表示（手順書）

要件定義書 第5章「init 後の再起動」と第13章 V8 の検証です。あわせて、2-4 で作った起動時の同期の表示が IDE のコンソールで正しく見えるかを確かめます。所要時間は IDE ごとに20分ほどです。

## 確かめたいこと

- **A. 再起動（V8）**
  - rok の R パッケージは rstudioapi に依存できません。そのため、base R だけで RStudio と Positron に R の再起動を指示できるかを確かめます。
  - 再起動の後に、プロジェクトの起動フック（`.Rprofile`）が走るか、作業ディレクトリが保たれるか、グローバル環境のオブジェクトが残るか（残るなら、要件どおり事前の確認が要ります）も見ます。
- **B. 起動時の表示（2-4）**
  - rok が R の起動時に出すメッセージが、IDE のコンソールに読みやすく出るかを見ます。
  - ソースからのビルドが要るときの3択（`menu()`）に IDE で答えられるか、R の版が違うときの案内も見ます。

## 前提

- V7 の `prepare.sh` を実行済みであること（試験用のプロジェクト `~/rok-ide-check` ができています）
- Positron と RStudio のうち、WSL の R を使えるもの。RStudio は、Windows 版のデスクトップでは WSL の R を使えないため、RStudio Server（WSL 内）か Linux 版が必要です。使えない IDE は飛ばし、その旨を記録してください

## A. 再起動（IDE ごとに）

1. IDE で `~/rok-ide-check` を開き、R のコンソールを起動します（Positron では R 4.5.x を選びます）
2. コンソールで `source("v08-restart.R")` を実行します
   - IDE の中にある再起動用の関数の一覧が表示され、`out/v08-result.txt` に残ります
   - 見つかった関数があれば、どれで再起動するかを尋ねられるので、番号で選びます
3. 再起動の後、コンソールで `source("v08-after.R")` を実行します
   - 新しいプロセスになったか、起動フックが走ったか、作業ディレクトリ、グローバル変数が残ったかが表示され、記録されます
4. 関数が複数あった場合は、2〜3 を関数ごとに繰り返します

あわせて、次の点も見てください。

- 再起動のとき、IDE が何か確認を出したか
- 再起動後のコンソールに、rok の1行（`✔ rok: rok-ide-check (R 4.5.x, ...)`）が出たか

## B. 起動時の表示（IDE ごとに）

ターミナルで状態を作り、IDE で R を再起動（Session > Restart R など、IDE の通常の操作で）して、コンソールの表示を見ます。

```sh
cd ~/rok-ide-check
./v08-scenario.sh light    # 1. 軽い同期：自動で直り「Restored in the library: R6」と出る
./v08-scenario.sh heavy    # 2. 重い同期：3択の質問が出る。「2」（ビルドしない分だけ）で答えてみる
./v08-scenario.sh ask      # 3. 尋ねる設定：同期してよいかを尋ねられる
./v08-scenario.sh reset    # 4. 同期済み：1行だけ出る
```

5. 最後に、R の版が違う場合です。Positron ではインタープリターをシステムの R（4.6）に切り替え、RStudio では R の版を 4.6 にして起動します。「This project requires R 4.5, but the current R is 4.6.x.」から始まる案内が出て、パッケージが見えない状態（`library(R6)` が失敗する）になるはずです。確かめたら R 4.5 に戻してください。
6. コンソールで次を実行し、rok の関数の途中経過が、処理中に少しずつ出るか（終わってからまとめて出るのではないか）を見ます。

   ```r
   rok::add("jsonlite")
   rok::status()
   ```

各場面で見てほしいことは次のとおりです。

- メッセージがコンソールに出たか。記号（✔ ! ℹ ✖ •）が文字化けしていないか
- 質問に IDE のコンソールで答えられたか
- 表示の順番がおかしくないか（rok のメッセージと R の起動時の表示が混ざらないか）

## Windows の場合（Windows の Positron・RStudio）

V7 の「Windows の場合」の準備（`prepare-windows.ps1`）を済ませてから行います。A・B の手順と記録用紙は上と同じで、違いは次の点だけです。

- **B の状態の切り替え**は、PowerShell で `pwsh -File v08-scenario.ps1 light`（`light`・`heavy`・`ask`・`reset`）を実行します
- **RStudio for Windows** は、レジストリに登録された R を一覧に出します。rok が入れた R 4.5 は登録しないので、一覧に出ないはずです（出たかどうかを記録してください）。R 4.5 で試すときは、Tools > Global Options > General の「R version」で `%LOCALAPPDATA%\Programs\R\R-4.5.x` を選びます（RStudio の設定が変わるので、終わったら元に戻してください）。システムの R 4.6 のままでも、A（再起動）と、B の 5（R の版が違うときの案内）は確かめられます
- **Windows の R のコンソール**の文字コードや記号（✔ ! ℹ ✖ •）の表示も見てください
